# Headless Components Overview

`@fotowl/media-ui-react` contains unstyled, accessible React UI primitives built to consume data from `@fotowl/media-react`.

## Component List

- **[MediaGrid](/components/media-grid)**: Grid layout container for collections of `MediaAsset` items.
- **[MediaCard](/components/media-card)**: Card component for individual media items with optional action slots.
- **[MediaSearch](/components/media-search)**: Complete search bar and paginated search grid wrapper.
- **[MediaPagination](/components/media-pagination)**: Accessible pagination controls (`hasNext`, `hasPrev`, `page`).
- **[MediaModal](/components/media-modal)**: Accessible modal dialog with focus restoration and `Escape` key close listener.
